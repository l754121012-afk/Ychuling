# 键位基线（暂定，待 M1.1 校准）

当前语义键位由 InputBootstrap 在启动时写入 InputMap：

| 语义 | 键盘暂定 | 手柄暂定 | 备注 |
| --- | --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆方向 | Crypt Custodian 参考版为 WASD |
| 跳跃 | Space | A | 待参考版校准 |
| 清扫/攻击 | 鼠标左键 | X | 攻击方向后续按鼠标/镜头校准 |
| 冲刺 | Shift | RB | 待参考版校准 |
| 互动/送走 | E | Y | 送走是本作主行为 |
| 地图 | M | Back | 待后续实现 |
| 暂停 | Esc | Start | 待后续实现 |

此文件不是最终冻结，M1.1 会打开 Crypt Custodian 设置页逐项修正，只把“校准结果”写进正式 `control-baseline.md`。
