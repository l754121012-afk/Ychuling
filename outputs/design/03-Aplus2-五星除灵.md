# A+2 方案：《五星除灵》

工作代号：`FIVESTAR`  
状态：待用户确认后再冻结正式 GDD  
制作规模定位：小而精、机制简单但有深度、以重玩为设计中心的荒诞除灵动作游戏

## 1. 一句话卖点

“你是深夜里唯一还在接单的除灵师：闹事鬼不是怪物，而是最难缠的顾客；把它们从沙发底、天花板和镜子里请出去，只换一句五星好评。”

## 2. 两句版本

“每单都写在今晚的派单表上，城区不大但你能快速赶到下一个现场，不会被困在小房间里。每清完一户，好评点亮下一条街；订单、街区和今晚处理得有多漂亮，拼出这一夜不同的收工结局。”

## 3. 从《Thank You Bus Driver》借什么，不借什么

它是荒诞喜剧方向上的机制参考，不是题材参考。

| 它验证过的优点 | 翻译进除灵方向 |
| --- | --- |
| 小体量但开车能快速浏览地图 | 一小块“夜班城区”，赶场/快穿让玩家总能看到下一条路线 |
| 每天规则、乘客与路线的变化 | 每晚派单表、闹事方式和街区组合随机变化 |
| 扇、撞、抓起扔出的夸张动作 | 扫把清扫、抓起小鬼、扔进收容符/窗户的舞台化表演 |
| “谢谢”是具体目标，不是抽象分数 | “五星好评”同时是时间、声望与目标 |
| 玩家知道自己在争取准时与认可 | 玩家知道自己在争取“今晚收工时被顾客记住” |

不借：公交身份、驾驶模拟、乘客上下客、同题材叙事。  
保留：Crypt Custodian 式俯视动作与键位、Isaac 式房间随机与构筑、Hollow Knight 式能力门解锁。

## 4. 世界与角色

深夜小城里有一家二十四小时营业的“上门除灵事务所”。普通人在午夜打来电话，说家里多了不该存在的东西。

玩家是刚入职的新除灵师：

- 扫把是工具也是武器，同时负责“扫”出看不见的鬼。
- 鬼不是纯恶意敌人，而是总在错误时间出现、占了错误位置的麻烦顾客。
- 顾客给你的不是伤害值或金币，而是“五星评价”；评价决定今晚还能接多少单。

## 5. 核心玩法

一局 = 一晚夜班。一晚由一条派单路线串联多个“上门现场”。

### 5.1 赶场层：城区快穿

- 每个夜班生成一张小型城区路线图，现场位置、顺序与岔路都不同。
- 玩家用快车/扫把/赶场技能在路线上快速移动，地图随时打开，下一个现场一直可见。
- 岔路通往隐藏单、道具摊、被封的街区；能力解锁后才允许进入，形成 Hollow Knight 式“看见-拿到能力-回来”的循环。
- 赶场不拟真，只保留“冲得快、选路、看到全城”的感觉。

### 5.2 上门层：Crypt Custodian 式清场

- 每单进入一个 Isaac 式小现场：客厅、浴室、办公室、仓库等房间随机组合。
- 玩家使用 Crypt Custodian 参考版键位/镜头移动、跳跃、清扫、冲刺、互动。
- 清场目标是“制造送走机会”：把鬼扫到失去闹事能力，再互动送进收容符/窗户/门口。
- 现场掉落除灵工具，工具之间可组合出新的清场方式。

### 5.3 闹事单层：问题从“投诉”开始

每单都有明确的“顾客投诉”，例如：

- “电视总是在凌晨自己打开，里面坐着一个灰影。”
- “厨房的锅会自己飘起来炒菜，但锅铲不见了。”
- “猫一直对着衣柜哈气，衣柜里有呼吸声。”

投诉决定现场目标，玩家先看到问题，再决定清扫顺序。行为从“读到投诉”开始，到“顾客回访给好评”结束，不是凭空刷怪。

## 6. 行为闭环

```text
夜班开始（随机派单表 + 城区 + 闹事组合）
   -> 查看第一单投诉（目标可见）
   -> 赶场到下个现场（地图快穿、选择岔路）
   -> 上门清场（看见问题-清扫-制造送走机会-送走）
   -> 顾客回访好评（获得时间/声望/工具）
   -> 下一单（更远街区、更难闹事、更多岔路）
   -> 今晚收工事件（按好评与处理结果落在不同结局）
   -> 回事务所升级（工具架、路线、能力门）
   -> 下一晚新派单表开局
```

## 7. 每次开局与结尾都不同

开局随机：

- 随机夜班城区、起始街区与派单表。
- 随机闹事单种类、房间组合与鬼的行为模式。
- 随机工具池与首轮可用道具。

结尾随机：

- “今晚收工事件”不固定成同一个 Boss，按好评数、超时、漏网小鬼与路线选择落档。
- 可能是常客请宵夜、大单镇魂仪式、越级投诉、被拖到天亮的隐藏单等不同收尾。
- 不同收尾解锁不同工具架与后续城区，让重玩目标是“看看这一晚怎么收工”，而不只是刷分。

## 8. 小体量设计

- 一张可被切分为 3 个街区的“夜班城区”。
- 每轮 6-10 个上门单，节奏按试玩调整。
- 第一版只做 6 种现场房间模板、3 种闹事鬼、1 种大收工事件。
- 美术全部先做几何体占位，按 ArtHost 替换契约接最终风格。

## 9. 目标受众

- 喜欢 Isaac 式短局重玩的玩家。
- 喜欢 Crypt Custodian/Hollow Knight 式清场与探索，但希望单局更轻量的玩家。
- 喜欢“工作模拟 + 荒诞喜剧”的玩家：上门服务、顾客投诉、五星评价容易产生切片记忆点。
- 适合的传播句：“半夜接到电话：衣柜里有人说谢谢。”

## 10. 盈利与行为闭合

- Steam 商店页 + 免费 Demo 提供“第一个夜班”，结尾展示收工事件与事务所升级。
- 正式版按夜班城区/工具架/收工事件扩展；Demo 结尾锁住第二街区，形成明确购买动机。
- 埋点看：第一单、第一次送走、第一次组合工具、第一次被差评、弃单原因。
- 不做抽卡；付费来自完整内容与可预期扩展。

## 11. 下一步验证

确认本方案后：

- M1 仍先做 Crypt Custodian 式键位/镜头可运行壳。
- M2 改为“1 条短派单路线 + 3 个上门现场 + 1 个收工事件”。
- 赶场先做轻量快穿，不做车辆模拟；上门清场是本作主要验证点。
