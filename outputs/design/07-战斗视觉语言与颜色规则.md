# 战斗视觉语言与颜色规则

目标：玩家不看任何说明，也能从“敌人做了什么”判断前后摇；颜色只在关键状态出现，不逐帧换全身色。

## 1. 颜色只保留三种语义

| 颜色 | 唯一含义 |
| --- | --- |
| 红色/红橙 | 敌人攻击警告、可命中区域、危险前摇 |
| 金色 | 敌人已经可 E 送走，常驻直到被送走 |
| 黄绿/白色闪光 | 玩家动作与命中反馈 |

敌人身体本身使用中性色，不再用红色/蓝色全身变色表达“它在攻击”。

## 2. 敌人身体结构

所有鬼都有可动“手臂”占位：

- 近身挥击：蓄力时手臂抬起，挥击瞬间出现红色地面弧光。
- 弹射光球：蓄力时单臂指向玩家，随后从手臂方向飞出光球。
- 蓄力冲锋：蓄力时双臂抬起/压低身体，随后直线冲锋。
- 地面落点：蓄力时双臂上举，地面出现红色危险圈。

### 武器与肢体规则

- 挥击类：宽刃武器，武器随抬臂和甩击动作运动。
- 冲锋类：长枪/长杆武器，蓄力时武器前指，冲锋方向与武器一致。
- 弹射类：法杖+杖端光球，蓄力时单臂瞄准玩家。
- 落点/冲击波：重型打击物，双持或单持上举后再砸地。
- Boss 额外使用双腿步行循环，移动时能看到步幅，攻击时脚步落定；所有武器与四肢会随 Boss 体型放大。

## 3. 玩家视觉

- 清扫命中：短暂黄绿弧光，不看颜色也能从范围看到结果。
- 陀螺：金色地面环 + 旋转动作，AOE 范围由动作本身表达。
- 受击：白色闪光 + 弹飞，之后正常移动，不强依赖颜色。

## 4. 后续美术约束

正式美术遵循：

- 敌人攻击前后摇必须用骨骼/肢体运动或投射物表现，不能用整身颜色变化替代。
- 红色只出现在敌人攻击瞬间或危险范围内。
- 金色只出现在送客判定上；正式角色颜色也不能污染状态色。
- 玩家与敌人都允许有自己的角色主色，但主色不得与状态色混淆。
