# 第二版本待办路线

当前项目已从原型阶段固化为 V1 稳定快照。第二版本不是推翻，而是在现有“五星除灵”闭环上做系统化和内容扩展。

## V1 已稳定保留的核心

- 3D 俯视角 Crypt Custodian 式移动/清扫/冲刺/跳跃。
- RMB：短按横扫重击，长按蓄满后松手进入 2 秒陀螺；蓄满有霸体。
- 碰撞：主动撞击、反弹、扫把推击、金色可吸收块、连携追击。
- 连携：只有玩家直接命中或直接撞击目标才开启 2 秒窗口；窗口内 RMB 固定触发连携。
- 生命：5 格液体容器；豆子上限 3，攻击积豆，静止长按 X 回血。
- 体力：15，冲刺扣 1，横扫重击扣 3，自动恢复。
- 失败：三小关内死亡回第一小关；Boss 阶段死亡回 Boss 前休息点。
- 敌人：普通小怪 HP 8、Boss 小怪 4、Boss 24；攻击全部带前摇/肢体/武器/投射物视觉。
- 关卡：1 条派单路线 + 3 个上门现场 + 收工 Boss + 3 小怪。

## 第二版本阶段

### Phase V2-A：把玩法做成系统

- 随机派单表与种子：不同夜班生成不同案件顺序、起点、隐藏单与收工事件。
- 事务所/车库：关卡外升级层，正式接入保存、失败结算、声望与解锁。
- 存档与休息点：完成“最近休息点”规则；不同大关拥有自己的检查点与解锁门。
- 房间与现场数据化：将 CASES 从硬编码数组改为 Resource/JSON 定义。
- 事件与送客：增加金色块的存在时间、特殊送客演出、多目标一次送走。

### Phase V2-B：深度与手感

- 手感表：移动速度、冲刺时长、攻击前摇、碰撞弹力做成可调参数并做一次平衡表。
- 无敌/受击/霸体状态细化：超装甲表现、红闪、受击打断规则。
- 连携打磨：追击是否要消耗体力/豆子，追击后的短旋转是否需要与豆子联动。
- 蓄力重击：满蓄后待命视觉、武器变色、能否移动、被击表现。
- 控制器支持与键位说明页。

### Phase V2-C：敌人与 Boss 内容

- 普通敌人池至少扩到 5-6 种，每种有独立移动/近战/远程/延时模式。
- 每种敌人使用一套“武器+肢体”动作模板，不再只改参数。
- 收工 Boss 做成三阶段：普通、狂暴、低血处决；每阶段替换攻击表。
- 增加两种第二区域敌人主题。

### Phase V2-D：表现与资产替换

- 美术方向定稿后导入第三方/自制资源，按 ArtHost 契约替换。
- UI 替换占位控件：生命容器、豆子、体力、地图、派单表。
- 正式动画：攻击前摇、被打飞、送客演出、Boss 招架。
- 音效与震动：命中、碰撞、蓄力、送客、受击。

### Phase V2-E：内容与盈利验证

- 可玩 Demo 第一章：事务所、3 条不同夜班、两个收工结局。
- 埋点：首次清场、首次碰撞连锁、首次连携、死亡次数、回血次数。
- Steam 页面雏形与截图素材。
- 数据表：通关时长、单局时长、好感/好评回收，是否支持买断定价。

## 里程碑定义

- V2.1：存档与随机派单闭环可玩。
- V2.2：手感参数与战斗规则完成平衡首版。
- V2.3：敌人/Boss 内容完成第二个大关。
- V2.4：美术替换完成一个可发布风格样本。
- V2.5：Demo 可玩并具备商店页素材。
