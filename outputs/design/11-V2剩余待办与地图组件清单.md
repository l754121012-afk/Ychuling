# V2 剩余待办与地图组件清单

## 已完成的本轮增量

- 重要互动演出：新增通用“光圈收束 -> 冲天光柱”特效，已接到夜巡印章拾取、Boss 清除、封印终点完成。
- 通用地图组件第一版：平台、柱子、可击破罐罐、装饰植物、流水瀑布。
- 首个地图装饰布局已加入当前路线，开始区分区域氛围。

## V2 剩余待办

### A. 互动演出覆盖

- 任务交付：NPC 对话后也应有光圈/光点收束特效。
- 能力拾取：夜巡印章已接入，后续能力都调用同一套演出。
- 门打开：能力门打开时应有对应开门演出，不只是消失。
- Boss 揭示：神秘鬼对话触发 Boss 时，应出现“区域封印解除”演出。

### B. 地图设计与地形

- 把当前横向路线拆成多个有区域身份的区块，不再“案件、NPC、战斗堆在一条街”。
- 为每个区块定义地形主题：
  - 夜巡司：平台低、植物少、休息点明确。
  - 居住区：可跳平台、杂物、房间残骸。
  - 旧剧场/电视台：柱子、灯位、高台。
  - Boss 封印场：空旷圆形舞台，四周高柱。
- 用平台高低差、窄缝、机关门控制玩家路线，而不是只靠门挡路。

### C. 通用组件扩池

已可用组件：

- 平台
- 柱子
- 可击破罐罐/杂物
- 装饰植物
- 流水瀑布

下一批组件：

- 可互动门（E 开门、能力门、Boss 门统一）。
- 压力机关与触发物。
- 可推动/可撞击的箱子。
- 移动平台或会升降的平台。
- 区域装饰组：灯、窗户、牌匾、灵火堆、雾区色块。
- 特殊景观占位：瀑布已有，后续补“夜晚河岸”“发光祭坛”“断层桥”。

### D. 地图数据化

- 每个区域写成 Region JSON，包含 zones、props、gates、quests、abilities。
- 区域加载后由 `V2EnvFactory` 按 props 数据生成占位场景。
- 使开发流程变为“改 JSON -> 跑地图”，而不是改代码堆节点。

### E. 探索与能力循环

- 地图上保留“可见不可达”目标。
- 每个新能力至少改变一次旧区域的路径或可击破物。
- 死亡后能力应能按未来正式存档规则保留，而不是每次都清空。

### F. Boss 与战斗区域

- Boss 从 NPC 揭示后进入独立舞台，不再沿用普通案件门。
- Boss 舞台需要战斗边界、阶段转场、受击演出。

### G. 随机派单与第二区域

- 案件顺序随机化。
- 制作“第二区域入口”只做解锁状态，不急着做完整内容。
- 存档把已完成能力/支线/Boss 写进 user://。

## 完成优先级建议

1. 把区域地图拆开并铺组件，让玩家有区域感。
2. 补齐能力门/任务交付的演出。
3. 完成第一区域“探索-能力-门-Boss-终点”存档闭环。
4. 再开第二区域入口。
