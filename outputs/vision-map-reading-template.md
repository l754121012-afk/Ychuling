## 必须输出的章节

### 1. 图片概况

- 图片尺寸、分辨率、横向/纵向方向。
- 是俯视地图、关卡平面，还是艺术示意图。
- 主推进方向：是否从西向东、从上到下。

### 2. 整体分区

- 把图片里肉眼能分的区域全部列出。
- 每个区域给一个名字与一个文字坐标范围。
- 标出：左下角区域对应的是哪一块、大致占多大、是什么主题。

### 3. 左下角区域细节

请单独把左下角区域展开，逐项记录：

- 房间/空间边界与形状。
- 主路、支路、死路、捷径。
- 平台、台阶、跳台的位置与高差方向。
- 柱子、箱子、可击破物、机关、门。
- 树木、瀑布、灯具等装饰的位置。
- 入口/出口朝向。
- 能进入但暂时锁住的区域。

### 4. 事件与实体

若图中出现以下符号，请逐个记录位置与含义：

- 玩家出生点 / 休息点。
- NPC。
- 案件点 / 事件点。
- Boss。
- 封印终点 / 目标柱。
- 门锁 / 捷径锁。
- 怪物出生点与朝向。

### 5. 视觉风格

- 用一段话描述整体风格。
- 描述颜色使用规律，例如红色、金色、白/黄绿分别用于什么。
- 描述房间线稿、道路、图例、指北、比例尺的位置。

### 6. 可直接进入实现的结论

请用代码开发能直接使用的形式写出：

```text
区域A（左下角）
范围：从 X=？到 X=？，从 Z=？到 Z=？
主入口：？
房间/平台：
  - ...
路径：
  - ...
事件点：
  - ...
机关/门：
  - ...
视觉主题：
  - ...
```

## 注意事项

- 禁止只输出“这是一张地图”之类的概括。
- 禁止跳过左下角。
- 若图片太小看不清文字，请注明“看不清”，不要补内容。
- 输出必须是一个开发者能照着搭地形的文本规格，不是艺术描述。
