# 雨城前两关地图细化

背景设定：忘川雨城常年下雨。雨水不是天气，而是“没来得及离开的执念”在空气中凝成的水汽。哪里雨最大，哪里就越接近灵界裂口。

## 第一关：城南雨市街

地图文件：[城南雨市街地图.svg](./城南雨市街地图.svg)

### 区域目标

- 看到：老剧院侧门被雨幕锁住。
- 探索：夜市、摊位顶棚、排水渠。
- 事件：清理“炒粉灰影”，获得夜巡印章。
- Boss：收伞人。
- 目标完成：用 Boss 掉落的“旧戏票”打开剧院侧门。

### 房间与事件

| 房间 | 功能 | 机关/玩法 |
| --- | --- | --- |
| 夜巡司天台 | 起始/休息 | 俯瞰全雨市，地图上标注剧院侧门锁 |
| 雨帘长巷 | 纵向走廊 | 屋檐流水、排水管作跳跃台阶，上段可到顶棚 |
| 摊位顶棚区 | 高层路线 | 高低遮雨棚跳台，房顶捷径需要夜巡印章 |
| 收摊水街 | 主街道 | 积水减速、可击破摊位杂物 |
| 炒粉灰影现场 | 案件一 | 灰影客人占据摊位，清场后出现夜巡印章 |
| 老巡夜员亭 | NPC/支线 | 对话揭示“印章是开旧门的凭据” |
| 印章高台 | 能力地点 | 获得夜巡印章，清扫伤害+1，旧剧院地图点亮 |
| 水洼后巷 | 隐藏支路 | 可击破瓦罐，通往药铺与排水渠 |
| 旧药铺 | 支线房间 | 药柜后的“雨前茶”叙事，解锁一次好评 |
| 排水渠 | Boss 房间 | 收伞人从积水里拔出无数雨伞攻击 |
| 剧院侧门锁 | 目标门 | 获得旧戏票后开启，进入第二关 |

## 第二关：旧剧院与封门车站

地图文件：[旧剧院与封门车站地图.svg](./旧剧院与封门车站地图.svg)

### 区域目标

- 看到：车站封印终点被锁住，但地图已标记。
- 探索：剧院大厅、后台吊杆层、车站寄存室。
- 支线：戏班主遗物揭示 Boss 弱点是“幕落瞬间”。
- Boss：末班车老板。
- 目标完成：获得封印钥匙，回到封印终点完成首夜封印。

### 房间与事件

| 房间 | 功能 | 机关/玩法 |
| --- | --- | --- |
| 剧院侧门 | 从第一关进入 | 打开后形成两关回环 |
| 散场大厅 | 主厅 | 观众席到二层包厢，楼梯与跳台 |
| 舞台池 | 中间 Boss | 幕布幽灵谢幕攻击 |
| 后台化妆室 | 支线/NPC | 戏班主提供“戏票钥匙”与弱点提示 |
| 放映间/幕布室 | 案件二 | 电视/幕布里的歌声，清场后获得戏票钥匙 |
| 吊杆层 | 高层探索 | 布景杆为移动平台，通往雨钟台 |
| 雨钟台 | 露天转场 | 连续雨台跳跃，能看到站台封印终点 |
| 寄存室 | 案件三 | 会呼吸的寄存柜，开柜后出现灵魂 |
| 站台区 | 主路 | 末班车轨道两侧可跳，Boss 前哨 |
| 末班车老板 Boss | 收工 Boss | 车灯扫射、车厢门砸击、钟声冲击波 |
| 封印终点 | 区域目标 | 获得钥匙后靠近按 E，完成首夜封印 |
| 地下维修通道 | 回环捷径 | 需要戏票钥匙，连通化妆室与站台 |

## 地图复用规则

两张地图都按“房间可复用 + 事件可换皮”制作，后续第三区域直接替换建筑主题，不再重做地图框架。
