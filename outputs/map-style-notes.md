## 一句话风格

暗色手绘 + 局部发光：深夜运河城，岛屿被青绿光辉点亮，四周沉入黑红酒红阴影，细雨斜织。

## 画面要素（按重要度）

1. **暗底近黑背景**：整体接近黑，四角和边缘呈深酒红 / 暗栗色（#1a0b0c–#3a1214），形成晕影压边。
2. **青绿发光海岛**：主区域用有机的青绿光斑（#6fe6c8 / #33b8a0 之类）呈现，边缘不是直线，是软润的不规则轮廓，像墨点晕开。发光区带淡青 halo。
3. **黑阴影团**：岛屿之间分布大块近黑阴影（树影 / 建筑剪影 / 云影），压在发光区之上，制造纵深。
4. **深窄运河**：岛屿之间是几乎纯黑、微微反光的窄水道，暗但有一点青/金反射；用细密暗色色带表现。
5. **金色挂锁**：门位用一枚金色挂锁（底座 + 锁体）标记；锁体与底座分开，金在暗底上最亮。
6. **Boss 红锯齿环**：Boss 封印区外围一圈红色（暗红 #8a1a1a → 亮红 #c22）锯齿 / 尖刺环，像王冠或禁区警示，向心放射。
7. **金色标签**：地名 / 门名用金色细体字，常在羊皮纸 / 暗金铭牌上，字体偏手写，不挤不重叠。
8. **雨丝**：全图覆盖稀疏斜向细线（浅青/浅灰，低透明度），让雨夜有流动感。

## 绘制建议（下次渲染时依次过）

- 底色：先填近黑 + 深酒红晕影 → 再铺深窄运河暗带。
- 发光：用径向渐变画青绿岛（每岛 2–3 层颜色，亮核 → 中调 → 淡 halo），边缘留软过渡。
- 阴影：在岛上叠墨色剪影（树 / 楼 / 压边），透明度 60–85%。
- 标记：金色挂锁放门位；Boss 区加红锯齿环；金色标签用 SystemFont 细体，白色描边 + 暗色遮罩保证可读。
- 雨丝：斜线 5–8° 随机长度，浅色低透明。
